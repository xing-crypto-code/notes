## 命名规范

`NN-章节名.pdf`

- `NN` 为两位章号，从 `01` 递增；封面页统一命名 `00-封面.pdf`
- 章号按课程内容顺序编排，便于顺序学习，也保证文件列表排序稳定
- 一章多个主题时用「、」连接：`02-角量与线量关系、牛顿三定律.pdf`
- 课后习题同样从 `01` 开始编号，或在章名后加 `-习题` 区分
- **一页笔记 = 一个 PDF**：自由笔记每页导出为一个文件，新增章节直接顺延编号

## 补充说明

- 单文件不超过 100MB（GitHub 限制）；仓库总量超过 1GB 时再考虑 Git LFS
- 自由笔记导出的手写笔迹是**矢量**，PDF 体积主要来自内嵌的黑板截图；导出时选择压缩可显著减小体积且不影响手写清晰度
- `_待归档/` 里的文件记得及时归位，别长期堆积
